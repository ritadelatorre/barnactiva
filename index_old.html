Presentación del curso

Bienvenido/a al curso de Fundamentos de la Programación con JavaScript. Esta fase está diseñada para adquirir una base de programación orientada a objectes (POO) que permita entrar con garantías a la siguiente fase, la especialización con mentoría.

Herramientas necesarias: Tener instalado el editor de codigo Visual Studio Code y cualquier navegador web.

Objectivos del curso:

  • Aprender la sintaxis básica de JavaScript
  • Trabajar con diferentes tipos de variables y constants
  • Aprender el funcionamento de les estructuras condicionales
  • Aprender cómo funcionan los arrays
  • Utilizar los diferentes tipos de bucles y saber cuál utilizar en cada caso
  • Trabajar con funciones
  • Entender y ser capaces de programar con POO
